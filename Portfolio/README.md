# Abdullah Aziz | Portfolio

A one-page portfolio built with HTML, Tailwind CSS (CDN) and plain JavaScript.

## Files
- `index.html` : the page content (hero, about, projects, skills, contact)
- `css/style.css` : theme colors (light and dark), theme switch, buttons
- `js/tailwind-config.js` : Tailwind colors and fonts
- `js/main.js` : theme switch, mobile menu, typing effect, copy-email button

## Run it
Double-click `index.html`. It needs internet for the Tailwind script and Google Fonts.

## Put it online (GitHub Pages)
1. Create a new GitHub repo and upload everything in this folder.
2. Repo Settings > Pages > deploy from the `main` branch, root folder.

## Things to edit
- Replace the sentiment app's GitHub link in `index.html` (search for the TODO comment).
- Once hosted, you can switch the "Copy email" button to a normal `mailto:` link.
